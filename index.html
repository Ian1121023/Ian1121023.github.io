02技能

Keeping the line running.

設備工程師在做什麼？

讓機台穩定、安全、有效率地運轉。從裝機到改善，每一個環節都需要軟硬兼備的能力。

  1. 01

    裝機與驗收

    機台進廠、配線、試車，確認規格與安全條件。

  2. 02

    預防保養 PM

    依週期點檢、更換耗材，把故障擋在發生之前。

  3. 03

    異常排除

    看電路圖、量訊號、拆解問題，最快讓機台復機。

  4. 04

    數據監控

    用感測器與微控制器收集稼動與健康數據。

  5. 05

    持續改善

    分析 MTBF / OEE，找出根因，提升良率與產能。

ESP32 讀取泵浦的振動、溫度與電流，超過門檻就亮燈並透過 MQTT 發出警報。試著模擬軸承磨損，再執行維修。

          看韌體程式碼（Arduino / C++）

// ESP32 vibration monitor — 每秒取樣並上傳
#include <WiFi.h>
#include <PubSubClient.h>
#include <Adafruit_MPU6050.h>

const float LIMIT_MM_S = 4.5;   // ISO 10816 class II 警戒值
const int   ALM_PIN    = 25;

void loop() {
  float vib  = readVibrationRMS(mpu, 1000);  // 1 kHz 取樣
  float temp = readTemperature();
  float amp  = analogReadMilliVolts(CT_PIN) * CT_RATIO;

  digitalWrite(ALM_PIN, vib > LIMIT_MM_S);
  mqtt.publish("factory/line3/pump1", toJson(vib, temp, amp));
  delay(1000);
}
